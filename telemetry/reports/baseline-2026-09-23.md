## Caveats

- Single machine, single developer. Directional, not a population estimate.
- `total_nano_aiu` is billed AI Units, which already fold in per-model multipliers;
  it is not a dollar figure.
- Tool-level findings (call mix, redundancy, failure rates, shell intent) come from the
  cloud session store and are reproduced via the `session_store_sql` tool using
  `queries/07`-`queries/09`. They are not produced by this script.

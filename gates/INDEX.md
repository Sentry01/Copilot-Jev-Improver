# Gate index

> Generated by `gates/build_index.py`. Do not edit by hand — regenerate it so the thresholds here always match the configs in force.

Every gate ships `SPEC.md`, `config.json`, `gate.py`, `example_state.json`, a recorded fixture and a dry artifact, and runs offline with no API key.

**Fail mode** is what the gate does when Jev cannot be reached or answers unusably. `closed` refuses to proceed; `open` allows. Every safety gate is `closed`, and their hard rules resolve locally *before* Jev is called at all, so an outage cannot unblock them.
